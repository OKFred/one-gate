# 硬盘资产采集关联实施计划

## 协作顺序

1. One Gate 完成详细设计、接口契约和本计划，再通知采集对话按同一 v1 合同实施。
2. One Gate 保存类型/测试基线，实施纯解析、两套目录查询和专用权限/API；采集对话同步实现私有身份读取、缓存、冻结关联、投影及合成模拟器。
3. 两边交换合成目录、请求及预期结果；合同差异先明确修订，不在各自仓库暗改。
4. One Gate 提供可执行的本地测试服务/样例和一次真正 assign 的 A→B 集成入口，采集对话运行跨仓库模拟，回传安全化证据。
5. 完成独立复核、格式/类型/相关测试及构建，记录实际落地与剩余边界；模拟验收覆盖全部阻断场景后交付。

## 采集端交付要求

1. 使用合成 D/E 和 A/B，保留 root helper 既有访问白名单；不更改容器、Broker ACL 或设备。
2. 在受限边界读取可靠 WWN/SN及型号，本地匹配目录；不把这些值混进公共缓存/MQTT/日志。
3. 冻结逐测点 asset_id/host_asset_id/assignment_id/catalog_revision/observed_time；增加版本化关联哈希和重放校验，原raw历史保持不变。
4. 验证用户无需修改采集标记配置，配置哈希不变；原始字段照实保留，源 metric 名、路径和实际读取主机可变。看板按 UUID + canonical_metric 连线并显示主机分段。
5. 给出可重复执行的一条模拟命令和只含合成信息的验收报告；说明已运行的模拟范围与未做的实盘范围。

## 验收矩阵

| 场景                  | 必须结果                           |
| --------------------- | ---------------------------------- |
| A/T-1 → B/T           | 同一磁盘UUID，不同归属ID，边界精确 |
| B/T-1、A/T            | 不误关联到当前所在主机             |
| 新盘占旧路径          | 按新盘身份识别，不能继承原路径资产 |
| A离线，迁移后重放     | 原UUID/主机/观测时间/哈希保持不变  |
| 同条消息两块盘        | 分别关联，另一盘完全不变           |
| SN/WWN冲突或占位      | 未知或冲突，不猜测                 |
| 仅旧mapping权限token  | 拒绝读取新硬件目录                 |
| 跨租户/无效host/撤权  | 拒绝访问；不泄漏标识               |
| 目录过期/断网         | 原始值继续保留，不新造关联         |
| 身份修改前旧观测      | 保守未知，旧已冻结决策不变         |
| 重复入队/ACK丢失/重启 | 相同确定性ID及完整关联哈希         |
| 隐私输出              | 公共输出无原始标识/路径/凭据       |

## 不确定项

若现有遥测source扩展无法保留冻结关联或结果哈希不覆盖它，采集对话需明确指出并实施版本化投影；不得以仅在 Grafana 硬编码名称替代本期闭环。模拟器如需额外系统运行时，先定位可用本地依赖；不因真实设备未指定而停下实现。
