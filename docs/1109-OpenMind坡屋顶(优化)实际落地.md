# OpenMind 斜坡屋顶

## 实际改动

按用户明确的斜坡屋顶要求，OpenMind 复用现有 OpenLife 双坡屋顶的绘制路径，移除平顶盖板和四条矮檐。不新增形状选项或建模抽象。

双坡沿原有参数在屋脊相接，保留透明材质、轮廓和 `depthWrite: false`。OpenMind 名称移至 `top + 1.75`，避免文字压住屋脊；OpenLife 的屋面和名称参数均保持原样。

仅修改 `platform/apps/personal/src/pages/asset/threeScene.ts`。屋面仍属于建筑结构，不加入设备拾取集合；设备 UUID、楼层状态、自动连线动画和默认列表行为沿用现状。无新依赖、接口、权限、数据库变更或迁移。
