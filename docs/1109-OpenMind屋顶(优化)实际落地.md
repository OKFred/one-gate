# OpenMind 屋顶可辨识性修复

## 实际改动

原 OpenMind 平顶盖板厚度为 0.12、填充透明度为 4%，中心与楼体顶沿重合，远看容易误以为没有屋顶。本次沿用场景现有 box 与主题颜色，将盖板放到顶沿上方，厚度调整为 0.24、填充透明度调整为 12%，并补四条相接的低檐边。

仅修改 `platform/apps/personal/src/pages/asset/threeScene.ts` 的 OpenMind 屋顶几何。保持透明材质和 `depthWrite: false`，屋顶仅属于建筑结构，不加入设备拾取集合。OpenLife 坡屋顶、楼层强调、设备 ID、自动连线动画及默认列表行为均沿用现状。无新依赖、接口、权限、数据库字段或迁移。

这是局部视觉修复，未扩展建筑编辑或材质配置功能。
