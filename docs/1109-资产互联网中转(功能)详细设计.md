# 资产空间图的互联网中转

在两栋房屋之间加入标注“互联网”的云形示意，连接改为 OpenLife ↔ 互联网 ↔ OpenMind，移除旧的房屋直连弧线。延续现有自动动态虚线和鼠标交互，不增加控制开关。

互联网属于 Three.js 建筑示意装饰，不是资产、场地或在线状态来源，不带 UUID、状态灯或资产详情。两条不相连的曲线使用同一 LineSegments 几何和虚线材质，复用现有距离相位动画、可见性暂停和销毁机制。

云形使用 Three.js 原生几何，无新依赖；颜色沿用主题色板。云和翻译后的名称加入结构组，随主题及语言刷新，并纳入相机适配。只允许业务资产加入设备拾取集合。

“互联网”通过中英文页面文案提供，空间图标题同步展示完整路径。保持资产清单、位置保存、设备身份、楼层、双坡屋顶和既有 2D 位置/主机关联拓扑的行为。

验证包括两段实际虚线动态、云图可辨认且不触发资产详情、原设备拾取和数量、主题、相机、移动视口、WebGL 生命周期。所有网络连线为示意，不代表联网探测结果。
