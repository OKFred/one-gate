# 首页极简详细设计

首页以少量信息为主：保留 AI、天地图快捷入口和单张 Cloudflare 摘要，最多显示 3 个用量行，优先展示已确认额度中最需关注的指标。首页不展示趋势图、时间筛选、完整指标卡、费用列表或技术说明。

“查看详情”进入 `/home?view=usage`，沿用现有完整用量界面，保留 1/3/7/30 天、折线/门槛线、费用分组、全部指标和覆盖明细，提供返回首页入口。地图仍通过 `/home?view=map` 访问。

摘要费用只在一个可合并分组时显示金额；多账期、币种、计费口径不相加，用分组数和详情入口表达。最多 3 项不是资源白名单，原始完整指标仍在详情。超限/高占用优先，并给全部关注项计数；未知额度、过期、采集失败或部分覆盖不显示全局“正常”。说明文字收至详情或必要的短状态。

摘要只请求 1 天历史，详情按用户选择请求；筛选仍只影响趋势，不改变各指标自身周期。保留认证隔离、权限检查、请求取消和乱序保护；无权限用户只有欢迎及有权使用的入口，不请求 Cloudflare 数据。

仅修改前端布局与文案，不修改统计口径、后端、数据库、权限、Secret 或采集调度。验证默认首屏简洁、详情可达、风险优先、未知与过期状态、英文/中文、320px/暗色、权限和地图/AI回归；执行前后 TypeScript、格式/lint、相关测试、构建及 git diff --check。
