## 行为冻结

- 企业、资产归属与人/机器身份由服务端验证；`tenantId` 不是客户端可自证的授权。
- 所有查询、数量、搜索、关联和最终写 SQL 都包含企业及当前授权条件。
- 同企业角色与系统角色分开；成员管理入口的最后有效 owner 变更有数据库保护。全局账号停用/删除导致无可登录 owner 时，企业常规访问按数据库条件冻结，由明确、可审计的平台恢复入口接管；普通资产 API 没有隐式平台全库旁路。
- 稳定 `asset_id` 不随名称、主机或位置变化。缺少 SN 可以建档，弱标识不自动合并。
- 唯一性与时效冲突按企业判断；同企业关联不得指向其他企业的资产或主机。
- 安装与测点映射分别保留，历史按原观测时间和半开区间解析，迁移与并发纠错不会部分提交；首期不支持未来生效排程。
- 首期退役保留历史，不把资产接入当前无企业 scope 的全局回收站或 30 天清理。
- 机器 Token 显式绑定企业且只有映射读取能力，不能继承创建者成员资格或管理资产；企业管理者只能授权本人创建、当前可用且未绑定其他企业的 Token。
- 不复制原始遥测，不自动同步生产 PG/Supabase，不顺带宣称其他 enterprise 业务已有租户隔离。

## 实施阶段

1. 企业与认证：可信主体、tenant/member、owner 保护和最终 SQL 授权，先通过跨企业和机器身份反例。
2. 台账与历史：资产/标识、安装/测点关系、区间/版本/原子迁移、退役历史保护与只读解析；Node 和 D1 同语义。
3. 页面与集成：企业切换、成员/台账界面、生成合同、中英文、隔离与乱序 UI 回归；代码构建与迁移演练后补交付记录。

## 必须验收的反例

| 场景                                           | 预期                                                                    |
| ---------------------------------------------- | ----------------------------------------------------------------------- |
| A 成员提交 B 的企业、资产、标识或历史 ID       | 不可见，数量及错误不泄漏 B 信息                                         |
| A 的安装或测点引用 B 的资产/承载主机           | 最终 SQL 拒绝，原关系不变                                               |
| 两企业相同 SN/名称/来源测点 key                | 按企业独立工作，无全库冲突或自动合并                                    |
| 一个用户有 A/B 成员关系，切换 A→B→A            | 旧列表、详情、表单、确认及延迟响应均失效                                |
| 撤回成员/停用企业与排队写入竞争                | 当前数据库授权条件决定结果，不能使用旧缓存继续写                        |
| 成员管理入口两个请求同时删除/降级最后 owner    | 至少保留一个有效 owner；全局账号停用/删除的无主状态有冻结与审计接管流程 |
| 旧 Token 或只获 A grant 的 Token 请求 B        | 拒绝，不能继承创建者的 B 成员关系                                       |
| 机器 grant 撤回或 Token 到期/吊销              | 后续线上解析立即拒绝，管理接口始终不开放                                |
| 同企业硬盘 A 主机迁移到 B 主机，旧数据离线补报 | 资产身份连续，按观测时间归属原安装/测点区间                             |
| 历史重叠、旧版本、并发迁移、批次后续语句失败   | 冲突或整批回滚，不能出现部分关闭/新建                                   |
| 退役及重新启用                                 | 旧读数仍可解析，不自动恢复已结束关系                                    |
| 全局回收站与普通未加企业范围的查询             | 不接触本期企业资产                                                      |
