# One Gate 开源迁移计划变更

1. 保存并验证完整私有 Git 备份与引用清单，冻结源提交。
2. 以“feat: 脚手架搭建”为边界，在独立候选库截断祖先及指向边界外的合并父引用，扫描全部保留历史；按实际发现移除私钥、运行材料并替换敏感配置。保留提交节点与合并拓扑，私有保存映射。
3. 更新 `README.md` 及中文入门说明、增加根 `LICENSE`、公开迁移说明；保留内部包名和第三方许可证。
4. 将 `.github/workflows/test.yml` 改为面向 `main` 的 GitHub 托管 CI。删除自动生产部署步骤与生产 Secrets 依赖。
5. 将环境示例、Wrangler 配置与相关运维文档中的部署标识改为占位配置；在必要范围内同步契约测试和模板说明。
6. 执行格式检查、TypeScript 前后对比、测试与构建；完成复盘和实际落地记录。
7. 建立独立新仓库，推送唯一 `main` 并验证 CI，完成公开验收后归档原私有仓库。调整已发布的历史边界时，额外私有归档上一版新仓库，再创建独立的同名仓库；保存备份和映射，并恢复分支保护、只读 Actions 权限及敏感扫描配置。

不变更业务接口、数据库结构或线上资源。历史文件清理范围依据扫描发现追加到私有报告，公开文档仅记录类别与验收结果。
