# TOTP 门禁退出实际落地

## 实现范围

- 二次验证页新增“退出登录”，复用中英文 topbar.logout；不要求验证码。
- 调用原 gate/logout 清 Cookie，5 秒超时；即使接口异常，也清除本地登录态。
- 取消待返回地址，移除 URL 中旧 Token 和 SSO 回调参数，以 replace 返回登录页。
- 验证与退出按钮互斥；同步认证事件使用更新后的登录路径，避免误执行已放弃的绑定回调。
- 不新增后端接口、数据库 migration、环境变量或权限，不退出 one 或修改身份绑定。
