# TOTP 门禁退出详细设计

## 背景与范围

主认证成功后，二次安全验证页面没有退出入口，无法放弃验证或更换账号。
在共享 TotpGateForm 增加退出按钮，由 AuthenticationBoundary 管理认证生命周期。
复用 gate/logout API 和已有中英文退出文案，不修改后端、数据库或登录方式。

## 行为与安全

- 退出不要求填写验证码；调用既有 gate/logout 清除 HttpOnly Cookie。
- 无论请求成功、失败或超时，都清除本地 Hodor Token；Cookie 与旧 Token 绑定，不能用于新登录。
- 清理待返回地址以及 URL 中的旧 token、SSO code/state/intent，replace 到登录页。
- 在清理 Token 触发同步认证事件前更新路径引用，避免回调页退出时重放旧回调。
- 退出与验证互斥，退出请求设有限超时；不加载菜单、权限或业务接口。
- 仅退出 Hodor，不撤销 one 会话、账号绑定或 Provider 授权。

## 验证

覆盖正常退出、退出接口失败、SSO 绑定回调中退出、转交 Token 清理、刷新不恢复旧登录。
执行前后 Admin TypeScript、受影响 Playwright auth 测试、Admin build、变更文件 lint/format。
独立 feature 分支合入 dev，保留与 one 修复不同的提交边界。
