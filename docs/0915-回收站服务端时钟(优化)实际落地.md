## 发布与后续边界

按现有 dev 流水线运行 CI、Worker 和三端 Pages 发布，核对精确提交与版本；线上只读验证 serverTimeUtc、页面读取／刷新、清理调度和数据库聚合计数。部署状态以 PR 后续记录为准，不将本地构建视为上线。

单个服务端时间戳不能消除网络单程延迟，浏览器估计可能略落后服务端；恢复接口始终重新检查。服务端重新采样到 SQL 实际执行也存在延迟，本轮不宣称数据库提交瞬间的绝对时间精度。

后续可按实际设备补充 OS 休眠验收。外部清理告警、备份恢复后的删除请求重放及其他业务资源迁移仍分别治理。本轮没有新增待处理的 TypeScript 诊断；既有 6 条涉及 mobile app-version/app/async-task repository 的 SQL 类型，以及两个历史测试脚本的模块问题，服务应用编译不受影响。
