# API 令牌一次性展示修复

## 问题与原因

创建 API 令牌成功后，后端返回 `{ ok: true, data: { id, rawToken } }`，HTTP
封装保留完整 AxiosResponse。页面从 `response.data.rawToken` 取值，实际明文位于
`response.data.data.rawToken`，因此没有打开已有的一次性展示弹窗。

数据库仅保存哈希和前缀；列表或详情不能还原已错过的令牌原文。

## 变更范围

- 修正 API 令牌管理页的响应读取，使用现有 OpenAPI 类型推导参数和响应，移除该页的 `any`。
- 沿用已有的一次性展示、复制及关闭清理行为。
- 增加使用合成凭据的浏览器回归：创建成功后展示原文，关闭后不再显示；失败不展示且不自动重试。
- 将新测试目录纳入现有前端 CI。

## 验证与发布

对比管理员应用修改前后 TypeScript 诊断，格式化变更文件，运行测试类型检查、定向浏览器测试和构建，执行
`git diff --check`。通过 PR 检查后，仅发布管理员前端；无需数据库迁移或后端更新。
线上新凭据提交和企业限定授权由使用者完成，不自动重建或更改已有令牌。
