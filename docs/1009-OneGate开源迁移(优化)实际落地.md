# One Gate 开源迁移实际落地

## 代码与仓库准备

- 项目公开名称为 One Gate，目标仓库为 `OKFred/one-gate`，开发主分支为 `main`，根许可证为 MIT。
- 以 2025-08-30“feat: 脚手架搭建”为根，保留共 1,181 个原提交节点，之后追加一个公开准备提交。原有 121 个合并节点中，一处引用边界外父节点的合并在截断后变为单父节点，因此最终有 120 个多父节点。保留范围内的作者、提交者、时间、内容和父节点映射均已校验；原始祖先及原仓库其他引用不发布。
- 完整备份已验证并从 bundle 恢复演练。备份、映射、原始扫描报告与替换规则保存在仓库之外的私有目录。
- 对历史私钥、停用的内部集成及编译页面执行全历史清理；部署标识改为占位值。第三方库保留原有归属信息。
- 根目录及前后端中英文说明统一名称和有效命令；新增公开迁移与部署说明。内部 `@hodor/*` 包名保持兼容。
- CI 改为 GitHub 托管 Linux runner、只读令牌、隔离测试配置；没有生产部署或生产 Secrets 依赖。敏感扫描继续继承默认规则，仅豁免精确路径中的已核对测试值及翻译键。
- Wrangler 使用资源占位 ID 并重新生成类型；AI REST 后备路径只读取部署者提供的账户 ID，取消私人账户后备值。

## 相对计划的补充

新增了三个必要修正：旧部署契约测试改为验证公开 CI 的隔离要求；初始化示例改为在导入前加载环境变量，确保使用明确配置的管理员；一并更正前后端子目录说明中的旧命令与路径。

规范内容未调整，只将规范索引中的个人绝对路径改为相对链接。未增加业务接口、数据库字段或迁移，未执行生产部署或数据写入。

## 历史边界更正验证

本次更正只改变 Git 历史边界和四份迁移文档。相对上一版公开准备，业务代码、依赖、测试、CI、部署占位配置及许可证的文件内容完全相同。所有保留的原提交与已清理历史逐一核对树对象，内容未发生变化；新根只有一个，不包含原始对象、替换引用或边界外祖先。

上表记录同一代码树已完成的本地验证，TypeScript 前后诊断基线一致；未将重复运行本地业务测试作为本次更正的证据。新历史另执行 Git 完整性、根快照和全历史敏感扫描、文档格式及差异检查，并由新仓库 CI 重新运行测试和构建。旧边界版本的恢复材料保存在私有归档，新仓库需完成匿名克隆、旧提交不可访问及保护配置验收。
