# 个人资产空间详细设计

日期：2026-11-08。开发基线：main `be3f035b`，分支 `codex/personal-assets-spaces`。

## 目标

在个人模块新增资产清单及房屋俯视空间。OpenLife 是本地单住宅层；OpenMind 是异地四层楼，支持 1F–4F 选择。场景与清单共享选择，详情显示设备状态、证据时间和展示位置。两地以动画虚线表达网络互联示意，不宣称链路健康。

房屋为示意图，不是真实户型。未确认位置保持“待定位”；不从主机名、IP、采集通道推断位置。不更改源 site_id、MQTT topic、clientId、硬盘身份或挂载历史。

## 数据与权限

企业资产继续作为唯一身份来源，以全局 UUID `assetId` 关联。页面复用现有有效企业选择；单企业自动选中。只返回该登录用户仍有权限读取的资产，遵守有效企业、有效所有者及成员校验。设备名称、分类、台账状态及明确的主机引用可投影；标识符、SN、WWN、业务位置、描述和采集内部身份不下发。

个人新增 `personal_asset_placement`，存 ownerUserId、tenantId、assetId、site、floor、version、更新时间。owner 来自人类登录身份，拒绝 API Token。site/floor 同时为空表示待定位；OpenLife 只允许 1，OpenMind 允许 1–4。按 owner/tenant/asset 唯一，首次写 expectedVersion=null，后续条件更新版本，避免旧页面覆盖。清除展示位置只写空映射，不删除源资产。

跨包调用通过企业公开 ServiceRegistry 的最小资产投影，不直接导入私有 service/repository。个人 `read/edit` 与企业资产读取权限同时校验；每次读取/修改重新验证源授权。私有布局保存不要求源资产编辑权限。

## 接口

均为 POST，前缀 `/api/v1/personal/asset`，响应 private/no-store。

- `/overview`：请求 `{tenantId}`；返回 `{asOfUtc,presenceSource,assets}`。每个资产含 `assetId,name,category,inventoryStatus,hostAssetId,placement,presence`。清单有明确上限，不能静默截断。
- `/place`：请求 `{tenantId,assetId,site,floor,expectedVersion}`；返回新映射。版本冲突明确报错，不自动重试写入。普通请求不能提交 owner 或设备在线状态。

SQLite/D1/PostgreSQL 使用相同业务合同；PG 仅显式放行本次已适配动作。新增编号迁移、定向生成 DDL，不运行全量初始化或清空历史迁移。

## 在线证据边界

当前 presence 候选尚无真实事件，没有可消费的 HTTP 接口或已批准的 One Gate UUID 映射。本期真实资产显示 `presenceSource=unconfigured`、`unknown/not_connected`，心跳等时间为空；不把温度缓存当在线证据，不创建新 MQTT 订阅。

演示使用独立、显式的合成数据模式，固定虚构身份和名称，不是请求失败的回退。显示在线、明确离线、心跳失联及未知四态；证据过期降为未知。观察链路失效始终未知，不能显示设备失联。VM/容器仅在有明确关系时作为物理主机子项，真实台账不从名称推断虚拟设备。

后续真实接入由私有批准映射关联 UUID，读取既有受限 presence reader。ACL、云表授权、费用、额外连接、硬件重启和磁盘扩容均不属于本轮授权。

## 界面

复用 MUI、原生 SVG 和 CSS，不新增 3D 依赖。斜俯视楼板、墙体和房内设备形成空间感；设备交互使用语义按钮。桌面两处并列，移动端场地切换；OpenMind 的楼层按钮可键盘操作。楼层内排列为示意，不保存未经确认的坐标。

状态含文字和图标，不只靠颜色。支持长名称、多设备、空清单、请求失败和无权限。减少动态偏好下关闭虚线动画。请求代际与身份隔离丢弃旧结果；刷新失败不冒充设备离线。文案使用中英文资源，时间使用 dayjs。

## 验证与交付边界

验证 owner 隔离、机器身份拒绝、企业授权撤回、脱敏投影、CAS、未知位置、源数据不变及迁移重复执行。前端验证选择联动、四层、待定位、虚拟子项、状态语义、请求乱序、身份切换、键盘、触屏和 reduced motion。

保留 TS 前后结果，执行变更文件格式/静态检查、相关测试及构建、差异隐私审查和 git diff --check。提供实际个人模块的本地可查看预览、截图及 PR，不将 mock 测试写成真实采集接通。未经新授权不合并 main、不部署生产、不修改 Cloudflare Access。
