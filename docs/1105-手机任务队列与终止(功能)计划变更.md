# 计划变更

1. 后端 `admin/mobile/async-task`：增加受限运行快照模型、严格解析与原子存储、按设备读取及终止服务，复用现有发布与权限；增加 Node/Worker 合同测试。
2. 设备上报与核心身份路由策略：只新增 `/admin/mobile/device/report/task-state` 一条机器凭据入口，复用启用设备及 `x-device-token` 校验；同步边界测试，保护其余路由。
3. 数据库：新增 D1 `0022_mobile_task_runtime.sql`、独立结构契约、新库 DDL与 Node 事务迁移；定向生成而不使用会重写历史的全量脚本。既有数据和迁移文件不改。
4. 前端：DeviceStatusDrawer 追加任务页签与 DeviceTaskPanel；共享 async-task API 封装、生成的 OpenAPI 类型、中英文 mobile 文案及隔离浏览器 fixture。保持原任务历史页与全局状态 enum 的含义。
5. 验证配置与文档：把新增 Node/Worker 与浏览器回归接入已有测试入口，输出实际落地记录和手机集成说明。

不新增依赖、一级页、菜单或可分配权限，不适配本期未开放的 PostgreSQL mobile 路由，不改手机仓库，不部署或操作真实任务。预期后台与手机需一并升级，旧手机显示“尚无队列快照”，不能显示假空闲。
