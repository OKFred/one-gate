# 软删除与回收站计划变更

- 公共层：新增软删除字段、期限及清理调度接口；抽取现有权限缓存失效辅助方法。
- 部门：模型、查询/写入条件、删除/恢复/清除/过期清理、错误翻译及相关测试。
- 关联：用户部门显式置空、用户/角色/子部门引用原子校验；不对用户和角色增加软删除字段。
- 回收站：后端 model/repository-adapter/service/index 与访问控制；前端独立页面、API封装、文案及UI测试。
- 初始化：回收站菜单、权限、业务键、响应Schema与生成的前端OpenAPI/权限常量。
- 调度：Worker和Node分钟入口接入固定注册资源，旧部门归档定向到期清理，结构化监控。
- 数据库：定向生成部门DDL、新增D1迁移/结构契约、Node一次性事务迁移脚本；迁移演练测试。
- 文档：补充维护窗口、备份恢复删除重放、GDPR适用边界与实际落地报告。
- 发布准备补充：独立 `maintenance-worker.ts` 维护入口及无数据库访问测试，用于首次换表前暂停 HTTP/分钟任务；正常部署入口保持不变。

不修改全局Git配置、无关规范、历史迁移、其他模块删除行为或生产数据库。本轮交付开发分支实现及本地验证；部署状态单独报告。
