# 天地图内嵌：实际落地

## 已实现

上一轮首页体验已通过 PR #9 合并至 main（8daae8de）。本轮从此基线建立 `codex/tianditu-map`，首页新增“天地图”入口，打开 `/#/home?view=map` 独立工作区。首页不提前请求地图配置或瓦片，地图与用量页面分别挂载，返回首页会清理地图。

`POST /api/v1/admin/base/map/config` 只向已登录且通过现有二次验证的人类用户下发配置。没有新增业务权限要求，API Token 被拒绝；既有认证例外名单和路由权限豁免均未扩大。接口仅读取 `TIANDITU_BROWSER_KEY`，经过格式校验后下发，未配置或非法时返回 false/null，禁止缓存并保留 Vary。没有任意配置查询、数据库变更、迁移或菜单/权限种子。

地图使用打包的 Leaflet 1.9.4，连接固定官方 HTTPS WMTS；提供全国初始视野、矢量/影像及注记切换、缩放、比例尺和初始视野。支持键盘和窄屏，保留供应商来源标注，不请求定位，不迁移旧业务绘图或私有地块数据。只在底图瓦片成功加载后显示可用，配置错误、瓦片错误及 15 秒超时使用局部提示与手动重试。

返回、离页、退出或身份修订时取消请求，清理 RAF、ResizeObserver、计时器、图层、图片监听和地图实例；迟到响应不能重新建立旧会话地图。浏览器 Key 不写入源码、静态制品或应用持久存储。浏览器实际瓦片请求仍会携带浏览器 Key，此设计不声称向已授权浏览器隐藏该值。
