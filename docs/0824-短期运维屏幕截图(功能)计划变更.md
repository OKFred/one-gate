# AutoJS6 短期运维屏幕截图计划变更

## 目标

在现有短期运维 WSS 中增加一次性全屏 PNG 获取能力，允许与前台任务并行且不操作前台应用；图片仅在当前浏览器内存中预览和下载。

## 预计变更

- one-autojs6 mobile：扩展固定操作与能力声明，增加有界 `screencap` 执行、PNG 校验、二进制制品封装、单截图并发和 WSS 背压处理，并补单元测试与运维说明。
- Node Server Worker：扩展操作白名单和设备能力校验，支持受限设备二进制帧的校验与直传，审计只累计大小并保存终态元数据。
- 管理端：增加能力门控的“获取截屏”、完整性校验、加载状态、预览、原图下载和 Blob URL 清理，并补中英文词条。
- 文档：更新短期运维协议说明，完成后补实际落地对比文档。

## 不变范围

- 不新增 HTTP API、数据库表或迁移、R2/S3 配置、PC 代理、Shell 或终端能力。
- 不启动 AutoJS 引擎，不进入或改变 MQTT 业务任务队列，不暂停或抢占前台任务。
- 自动验证不调用 ADB；真机验收等待用户单独授权。

## 验证

- one-autojs6：格式化、类型检查、mobile 测试和构建。
- Node Server：Worker Vitest、相关 Node 测试、管理端 lint/typecheck/build、服务端构建。
- 两个仓库：`git diff --check`、LF/BOM 与意外生成物检查。
