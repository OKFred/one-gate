# 硬盘资产采集关联接口契约 v1

日期：2026-10-24。状态：v1 实施基线。One Gate 基线 `7ea08c7e`，分支 `codex/hardware-asset-linking`。

## 目标与责任

首期只做合成数据模拟：同一硬盘从主机 A 的一个路径、测点名迁移到主机 B 的其他路径、测点名，固定资产 UUID 不变，不修改采集标记配置，历史曲线按资产连续展示。用户已明确无需实盘移动或停机验收。

One Gate 是唯一资产主数据来源，维护资产、已确认标识和按时间生效的安装关系。采集端只读获取身份目录，在入持久化发件箱前冻结逐指标关联；ingestor 和 Grafana 消费该关联。普通采集账号不能修改资产、标识、安装关系或测点绑定。

现有四张资产表复用。迁移使用现有 `assign(replacesId, expectedUpdateTimeUtc)` 原子结束 A 归属并开始 B 归属。新链路按硬件标识解析 UUID，无需自动改写现有 measurement binding；旧 mapping/list、mapping/resolve 保持原合同。

## 身份与范围

- 对外资产身份使用 `enterprise_asset.asset_id` UUID。内部数字主键不能作为跨库身份。
- hostAssetId 为 One Gate 主机资产 UUID，每个采集主机首次配置一次，不用主机名、盘符、PCI 槽位或指标名充当硬盘身份。
- v1 自动匹配仅使用类别 disk、`isVerified=true` 且 `confidence=high` 的标识。目录可包含退役资产供历史匹配，但退役时刻及之后的新观测不匹配。
- `identifierType=wwn, namespace=storage.wwn`：沿用现有 WWN 规范，移除首部 0x、冒号、空白及短横线后转小写，必须是非全 0/全 f 的 16 位十六进制。128 位 NGUID 不压缩为 WWN，留待后续版本。
- `identifierType=sn, namespace=storage.serial`：SN 仅 trim，保留大小写、前导零及有意义字符；沿用现有占位符拒绝规则。仅 SN 模式必须提供非空 model，并与资产 model 的 trim 结果精确匹配（不额外规范化 Unicode）。同时提供 WWN 时以 WWN 作为身份和生效时间证明，SN 只用于检测矛盾。该命名空间中的已确认 SN 在租户内保持唯一；重复 SN 不自动合并。
- 原始 SN、WWN、设备路径只处于受限身份查询和私有目录缓存中，不能进入公共温度缓存、普通日志、MQTT、原始云端归档或 Grafana。模型规则本身不是匿名化保证。
- trim 及 WWN 内部空白去除严格采用 ECMAScript WhiteSpace + LineTerminator 集合，与现有服务端一致；Python 不能直接使用 str.strip 或默认正则 \s（如 U+FEFF、U+0085 语义不同）。共享规范化测试覆盖这些字符。
- 现标识表没有历史区间。WWN 的 `effectiveFromUtc=max(identifier.createTimeUtc, identifier.updateTimeUtc ?? identifier.createTimeUtc)`；SN 则还取资产 create/update 时间的最大值，以覆盖型号变化。资产任意编辑后，尚未固化且早于编辑的 SN-only 观测保守未知；WWN 不受资产资料编辑影响。更完整的标识历史另行扩展。

## 权限和通用约束

新增 `enterprise.asset.telemetry:read`，因为目录会暴露已确认硬件标识；旧 mapping:read 不自动获得这些数据。人类账号需同时拥有该权限和可用企业成员身份。API token 需该权限、既有 mapping:read（用于现有 tokenGrantSet）以及该租户的有效 grant。SQL 守卫再次核对租户启用、有效所有者、账号/令牌及固定服务端权限。

首期授权粒度为租户，不声称实现逐主机 token scope。host 必须属于请求租户且类别为 host。不能通过客户端参数指定权限码。禁用企业/所有者/令牌/grant 后新查询立即拒绝。

以下接口全部 POST，位于 `/api/v1/enterprise/asset/telemetry`，外层沿用现有 `{ok,message,data}` 和业务错误合同。客户端同时识别 HTTP 错误与 `HTTP 200 + ok:false`，不匹配翻译文案。响应不得经共享 HTTP 缓存，使用 `Cache-Control: private, no-store`。

## POST /catalog

请求：

```json
{
  "contractVersion": 1,
  "tenantId": 1,
  "hostAssetId": "11111111-1111-4111-8111-111111111111"
}
```

data：

```json
{
  "contractVersion": 1,
  "tenantId": 1,
  "host": {
    "assetId": "11111111-1111-4111-8111-111111111111",
    "status": "active",
    "retiredTimeUtc": null
  },
  "revision": "sha256:<64 lowercase hex>",
  "serverTimeUtc": 2000000000000,
  "expiresTimeUtc": 2000000900000,
  "assets": [
    {
      "assetId": "33333333-3333-4333-8333-333333333333",
      "status": "active",
      "retiredTimeUtc": null,
      "model": "SIMULATED-DISK",
      "identifiers": [
        {
          "identifierType": "wwn",
          "namespace": "storage.wwn",
          "value": "5000000000000001",
          "effectiveFromUtc": 1999999990000
        }
      ],
      "assignments": [
        {
          "assignmentId": 101,
          "hostAssetId": "11111111-1111-4111-8111-111111111111",
          "validFromUtc": 1999999990000,
          "validToUtc": null
        }
      ]
    }
  ]
}
```

- assets 包含授权租户可自动识别的磁盘及完整安装区间，包含已关闭区间；不会返回业务备注、人员信息或全部资产详情。标识只返回规范值。
- 一次请求返回完整目录，禁止返回混合版本的分页片段。两种数据库使用一条有界 SQL 完成 host、权限、资产、标识、安装关系的一致读取；实现可将连接行去重后投影。
- 上限为 5000 个连接行（查询 LIMIT 5001 以检测超限）、1000 个磁盘、4000 个标识、4000 个归属区间、1 MiB UTF-8 响应 data。任一上限超出则整体失败，稳定业务码 `errorHandler.enterprise.asset.telemetry.catalogTooLarge`，不返回截断目录。
- revision 对 `{contractVersion,tenantId,host,assets}` 的 canonical JSON 做 SHA-256，加 `sha256:` 前缀。对象键按 UTF-16 code unit 升序递归排列；不得先放入普通 JS 对象再依赖 JSON.stringify 的整数键重排。数组顺序固定：资产按 UUID；标识按 type、namespace、value、effectiveFromUtc；归属按 validFromUtc、assignmentId、hostAssetId（null 排在字符串前）。所有字符串比较也使用 UTF-16 code unit 顺序，数值按数值升序。时间和 expiry 不参与哈希。
- canonical JSON 无空白，UTF-8 编码，非 ASCII 字符不转义、不额外规范化 Unicode。仅允许 null、boolean、无孤立代理项的字符串、安全整数（绝对值不超过 9007199254740991）、数组和普通对象；拒绝 undefined、浮点和稀疏数组。字符串按 JSON.stringify 转义（控制字符、双引号、反斜线），斜线和 U+2028/U+2029 不额外转义。双方共享含中文、emoji、数字对象键及特殊 SN 的黄金 fixture 和预期 SHA-256；不得用 max(updatedAt) 代替内容哈希。
- TTL 固定 15 分钟（900000 ms），每次成功获取可刷新租约。采集端按服务端时间校准租约，不因重渲染、读缓存或重试延长。完整校验版本、身份范围、revision 后原子替换目录；错误/半份目录不覆盖有效旧目录。
- 缓存按服务地址、租户、主机及凭据身份隔离；文件为受限私有文件。401/403 或任何明确应用拒绝都停止新关联并清理该身份目录；网络/5xx 未明确业务拒绝时，只可在原 TTL 内继续旧目录。TTL 到期仍可继续原始采集，但不产生新的 resolved 关联。
- 离线期间无法立即获知撤权，最长 TTL 是明确边界；已固化的历史关联不因缓存过期而重写。不得通过最新目录猜测登记/修改标识之前的旧观测。

## POST /resolveBatch

请求：

```json
{
  "contractVersion": 1,
  "tenantId": 1,
  "hostAssetId": "11111111-1111-4111-8111-111111111111",
  "items": [
    {
      "requestId": "sample-1",
      "observedTimeUtc": 2000000000000,
      "model": "SIMULATED-DISK",
      "identifiers": [
        {
          "identifierType": "wwn",
          "namespace": "storage.wwn",
          "value": "0x5000000000000001"
        }
      ]
    }
  ]
}
```

最多 100 项，每项 requestId 非空、批内唯一，最多 4 个标识；model 可为 null，仅 WWN 模式不强制提供。缺失标识允许返回明确未解析。观测时间为 UTC 毫秒整数，负数/结构错误由请求校验拒绝；超过服务端时间 5 分钟的值不自动关联。

data 为：

```json
{
  "contractVersion": 1,
  "revision": "sha256:<64 lowercase hex>",
  "serverTimeUtc": 2000000000000,
  "expiresTimeUtc": 2000000900000,
  "results": [
    {
      "requestId": "sample-1",
      "observedTimeUtc": 2000000000000,
      "status": "matched",
      "reasonCode": "MATCHED",
      "mapping": {
        "assetId": "33333333-3333-4333-8333-333333333333",
        "hostAssetId": "11111111-1111-4111-8111-111111111111",
        "assignmentId": 101,
        "assignmentValidFromUtc": 1999999990000,
        "assignmentValidToUtc": null
      }
    }
  ]
}
```

未匹配或冲突时 mapping 必须为 null；不返回“最可能”的候选。接口与目录本地解析使用同一算法，不能逐项独立读取不同版本的目录。

固定状态为 matched/unmapped/conflict；固定 reasonCode：

| reasonCode                         | 含义                                 |
| ---------------------------------- | ------------------------------------ |
| MATCHED                            | 唯一身份及该时刻主机归属均匹配       |
| MISSING_IDENTIFIER                 | 无可用标识                           |
| INVALID_IDENTIFIER                 | 格式/占位符不可信                    |
| UNSUPPORTED_NAMESPACE              | 不在 v1 命名空间内                   |
| WWN_UNMAPPED                       | 提供的有效 WWN 不存在，不降级使用 SN |
| IDENTIFIER_UNMAPPED                | 无已确认高可信身份                   |
| IDENTIFIERS_DISAGREE               | 多个已命中标识属于不同资产           |
| MODEL_REQUIRED / MODEL_MISMATCH    | SN 模式缺少型号或不一致              |
| IDENTIFIER_NOT_EFFECTIVE           | 观测早于身份最近创建/修改时间        |
| ASSIGNMENT_MISSING / HOST_MISMATCH | 当时没有归属，或属于其他主机         |
| ASSIGNMENT_CONFLICT                | 当时存在多个有效归属                 |
| ASSET_RETIRED / HOST_RETIRED       | 观测位于相应退役时刻及之后           |
| INVALID_OBSERVATION_TIME           | 观测时钟超出允许范围                 |
| CATALOG_EXPIRED                    | 本地目录租约到期                     |

IDENTIFIERS_DISAGREE、ASSIGNMENT_CONFLICT 使用 conflict；其他非 MATCHED 使用 unmapped。

解析按下列固定优先级，标识输入顺序不能改变结果。nowTimeUtc 为服务端当前时间，或采集侧校准后的当前时间，不能固定为旧目录的生成时间：

1. `nowTimeUtc >= expiresTimeUtc` 为 CATALOG_EXPIRED；随后检查观测为非负安全整数且不超过 nowTimeUtc + 300000，否则 INVALID_OBSERVATION_TIME。
2. 无标识为 MISSING_IDENTIFIER；任一标识类型/命名空间不支持为 UNSUPPORTED_NAMESPACE；随后任一格式/占位符错误为 INVALID_IDENTIFIER。
3. 规范值去重后查找全部命中。多个已命中标识属于不同 UUID，或同一标识意外命中多个 UUID，返回 IDENTIFIERS_DISAGREE。随后有任一有效 WWN 未命中为 WWN_UNMAPPED，不能降级 SN；没有任何命中为 IDENTIFIER_UNMAPPED。
4. 有 WWN 时只用 WWN 的 effectiveFromUtc 作时间证明；SN 为矛盾检查，不要求型号。仅 SN 时依次检查 MODEL_REQUIRED、MODEL_MISMATCH，再检查所用身份 effectiveFromUtc。多个证明取最大 effectiveFromUtc；早于该时间为 IDENTIFIER_NOT_EFFECTIVE。
5. 先检查 ASSET_RETIRED，随后 HOST_RETIRED（观测时刻 >= 退役时刻）。最后以 `[validFromUtc,validToUtc)` 匹配：零个区间为 ASSIGNMENT_MISSING，多个为 ASSIGNMENT_CONFLICT，唯一但主机不同为 HOST_MISMATCH，否则 MATCHED。不能 fallback 到原路径或原 metric 名关联。

## 逐指标冻结关联

MQTT 新消息可将关联置于受控扩展 `source.asset_association`。不修改已有原始报文字节、ID 或原始哈希。示意：

```json
{
  "contract_version": 1,
  "catalog_revision": "sha256:<revision>",
  "host_asset_id": "11111111-1111-4111-8111-111111111111",
  "metrics": {
    "disk_temperature_c": {
      "status": "matched",
      "reason_code": "MATCHED",
      "asset_id": "33333333-3333-4333-8333-333333333333",
      "assignment_id": 101,
      "assignment_valid_from_utc": 1999999990000,
      "assignment_valid_to_utc": null,
      "canonical_metric": "temperature_c",
      "observed_time_utc": 2000000000000,
      "time_basis": "collector_read_time"
    }
  }
}
```

同一消息内每个测点分别关联；有 per_metric_read_time_utc 时使用它，不用批处理/入库/补报时间。canonical_metric 来自采集器已知的类型及单位，本期温度为 temperature_c；不能从名称猜测不同物理量或混合单位。用户无需修改采集标记配置，原始来源和指标字段照实保留；曲线按 UUID + canonical_metric 归并，路径/源指标名变化不打断。无可靠身份时保留数值及未解析状态，不能把它当作温度缺失。关联在首次持久化入队之前冻结，重试、重启、补报和目录更新均不改写。

matched 同时冻结 assignment_valid_from_utc/assignment_valid_to_utc；unmapped/conflict 的 asset_id、assignment_id 及这两个区间字段全部为 null，均进入完整关联哈希。尚无目录或收到明确拒绝并清除目录时省略整个扩展，保留原始温度，不编造 revision 或新 reasonCode；仍持有过期目录时可以其原 revision 生成 CATALOG_EXPIRED。

采集侧新增版本化 association 投影/processor，将完整 canonical 关联纳入结果哈希和确定性输出校验；现有仅覆盖 payload 的哈希规则不够。旧 processor、历史 raw 和旧哈希规则保持兼容。无法在既有 source 扩展承载时，先报告具体差异再协商，不能自行改名或破坏去重合同。看板只选择一个明确的投影版本，避免新旧重复计数。

## 合成验收基线

合成主机 A/B、硬盘 D/E，登记发生在采样前。D 的身份固定；在 T 时刻以 assign(replacesId) 将 D 从 A 迁移至 B。D 在 A/T-1 与 B/T 均为 matched，资产 UUID 相同、归属 ID 不同；A/T 为 HOST_MISMATCH，B/T-1 为 HOST_MISMATCH。

同时模拟路径、槽位和 metric 名变化，采集配置文件哈希保持不变；E 占用 D 的旧路径时仍识别 E。A 的 T 之前消息离线入队，迁移后重放仍保持 D/A 及原关联哈希。补齐目录过期、撤权、标识冲突/修改、同消息多盘、租户隔离和重试幂等场景。

模拟 reader 只访问测试预先批准的合成设备；不移动硬盘、不扫描全部磁盘、不变更 DeviceAllow、不更改现有运行容器。真实采集授权和发布属于后续独立验收。
