# 个人资产空间实际落地

日期：2026-11-08。开发分支：`codex/personal-assets-spaces`，基线 main `be3f035b`。

## 已实现

- `/personal/asset`：OpenLife 单住宅层、OpenMind 四层斜俯视 SVG 空间；原生语义设备按钮、楼层切换、中性动态虚线、列表/详情联动、名称/场地/状态筛选、分页、待定位与关联子资源。
- 当前人类用户的私有展示映射；服务端 owner、位置配对、版本 CAS、源资产/企业/权限最终 SQL 条件。重置位置不删除台账，不改 UUID、采集标记或挂载历史。
- 企业通过公开 ServiceRegistry 提供最小投影；有效挂载按半开区间投影主机 UUID。保留退休台账状态，超过 1000 项返回明确上限错误，不返回不完整清单。
- `POST /api/v1/personal/asset/overview`、`/place`，响应 private/no-store；个人 read/update、源企业资产 read，页面选企业另需现有企业 read。
- SQLite/D1/PG 表与 repository、定向 DDL、结构契约、增量菜单/权限/翻译、OpenAPI 与生成权限。旧编号迁移未改。
- 真实资产固定为 `unconfigured/unknown` 和空在线证据；显式演示另有四状态、过期证据、虚拟机/容器子项。失败不切换演示；期限到达即时降未知，切身份丢旧响应，写入不自动重试。

## 与计划的差异

采用斜俯视 SVG 剖面形成空间感，没有引入 WebGL、摄像机或新依赖。移动端两处场景纵向排列，楼层与清单仍可触屏/键盘访问；未增加移动场地切换器。楼层上只展示有限代表标记，完整设备通过“查看 N 台”、筛选与分页访问，未静默丢弃列表。

真实资产分类仍来自企业台账，不增加 VM/容器身份模型；虚拟子资源只在显式合成演示中存在。真实源分类/明确关系尚不具备时不推断。尚未接通 presence，不导入候选登记、不编造位置或上线状态。

额外补齐 CI 对本功能的独立个人页面测试、fixture 专用类型检查，以及 personal 包 enterprise 路径映射。测试运行真正的个人资产组件，没有空 federated remote 冒充页面验收。
