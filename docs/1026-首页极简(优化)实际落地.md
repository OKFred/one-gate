# 首页极简实际落地

## 已完成

默认首页只保留欢迎标题、AI/天地图入口和单张 Cloudflare 摘要。摘要最多 3 行，按硬上限/容量、内含量超额、80% 预警及已确认占用程度排序；关注项数量仍统计全部指标。单费用分组显示精确金额，多分组只显示数量，不跨币种、周期或计费口径合计。未知、过期和部分采集仍有短状态，估算值保留 `≈`，参考值保留质量说明。

完整用量移至 `/home?view=usage`，保留图表、1/3/7/30 天、全部指标、费用分组与覆盖明细；行点击会选择对应指标，返回首页清空详情弹窗。首页只请求 1 天历史，详情使用所选范围，保留权限、会话、取消及迟到响应保护。手动刷新只出现在详情页，地图视图保持独立。

与计划一致；额外修正了旧测试 fixture 对生产企业/个人远端模块根路径的隔离，避免用真实生产服务补本地测试。没有修改后端、共享请求层、数据库、权限、Secret 或调度。
