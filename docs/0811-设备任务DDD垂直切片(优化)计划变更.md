# 设备任务 DDD 垂直切片计划变更

## 1. 后端计划

1. 新增 `async-task/domain/`，承载任务聚合、协议契约、可信脚本规则和领域异常。
2. 新增 `async-task/application/`，承载端口、下发/查询/结果/超时用例、处理器注册表和稳定 Facade。
3. 新增 `async-task/infrastructure/`，迁移 Drizzle Repository、MQTT Publisher 和默认依赖装配。
4. 新增 `async-task/interfaces/http/`，承载回调 URL 等 HTTP 专属适配。
5. 精简根 `service.ts`，保留现有四个 POST API 与 JSON Schema 组合。
6. 更新 `mqtt/listener.ts`、`mobile/device-app/service.ts`、`mobile/index.ts` 和 Worker 入口，统一依赖 Application Facade。
7. 保留根 `model.ts` 的数据表与 API Schema，但从 Domain 引用状态、优先级和可信脚本枚举。

## 2. 前端计划

1. 将异步任务页的 `SchemaCrudConfig` 提升为模块级常量。
2. 新增独立 `TaskStatusChip`，集中状态与 MUI 语义色映射。
3. 保持现有只读列表、筛选、列和 API 行为。

## 3. 测试计划

1. 新增 Domain 规则单元测试。
2. 新增 Application Fake Ports 单元测试。
3. 新增 HTTP Service 契约测试。
4. 对比修改前后 TypeScript 诊断，执行服务端与 admin 前端构建。
5. 对变更文件执行 ESLint/Prettier，完成规范复盘和 `git diff --check`。

## 4. 兼容边界

- 不修改数据库、DDL、Migration、权限、菜单和翻译。
- 不修改 HTTP 路由、请求响应、OpenAPI 和 MQTT v2 协议。
- 不修改 `one-autojs6`。
- 不实现取消、Outbox、事件历史或新状态。

## 5. 预期文件影响

- 新增：`server/packages/admin/src/mobile/async-task/{domain,application,infrastructure,interfaces}/` 与对应测试。
- 修改：异步任务根 `model.ts/service.ts`、Mobile 组合入口、MQTT Listener、Device App Service、Worker 入口。
- 修改：异步任务前端页面、表格配置及新增状态组件。
- 新增：本功能详细设计、计划变更和最终实际落地文档。
