# 资产空间互联网中转实际落地

## 实际行为

3D 空间图改为 OpenLife ↔ 互联网 ↔ OpenMind：两屋之间显示带本地化名称的立体云形，原房屋直连弧线改为两段独立曲线。两段共用 LineSegments、虚线材质和距离相位，240 个顶点均参与现有自动动画；不增加连线或播放开关。

互联网只属于场景结构，不生成资产、UUID、在线状态灯或详情入口。两屋稍拉开间距，连线端点根据房屋中心计算；云形及名称纳入相机适配。云体挡住设备时，鼠标悬停和点击不会穿过云误选后方资产；未被遮住的设备仍可正常拾取。

中英文新增一个互联网词条，场景标题展示完整路径。资产清单、位置保存、楼层、双坡屋顶、设备身份及 2D 位置/主机关联拓扑沿用现状。没有新增依赖、后端接口、权限或数据库变更。

## 与计划的比较和复核

两轮复核完成。第一轮代码和 32 项回归通过，但实际默认预览中云与 OpenLife 重叠，独立射线检查还发现不透明云可能被点击穿透。暂存首版后，第二轮调整了两屋间距和云的位置，并补最近遮挡判断。实际 Chrome 确认默认布局清楚、旋转遮挡时不误选；第二轮独立复核无阻断。

较计划补充了明确的云遮挡拾取规则，落实互联网不是资产的交互边界。没有扩展网络检测、真实连接配置或额外控制项。

## 验证

- 变更文件 Prettier、ESLint 通过；个人端 TypeScript 改动前后均为 0，E2E TypeScript 通过。
- 最终个人资产模型与真实浏览器回归 32 项全部通过，个人端生产构建通过；保留原有大 chunk 提示。
- 新用例实际拖动 Orbit 相机，使云与 Atlas 投影间距小于 2 像素，点击该设备投影不打开详情；重置后同一 UUID 能正确打开。清单仍 9 项、已定位物理拾取目标仍为原 8 个 UUID，云不改变楼层或设备数。
- 既有真实 WebGL 像素帧、自动动画、可见性暂停、主题保持相机、失效降级、设备跨层拾取及身份隔离回归保持通过。
- 外部 Chrome 明暗主题下检查云形、名称、两段曲线和双坡屋顶；主题切换相机保持一致。390 × 844 窄屏模拟未裁切，检查后恢复原视口。窄屏模拟不是实际手机验收。
- `git diff --check` 通过。

## 发布与边界

按 PR 检查通过后合并 main、仅发布个人端 Pages 的流程交付；实际部署版本、回滚点和线上 Chrome 验收证据记录在仓库外发布目录，线上结果以该记录为准。

不执行数据库业务写入、迁移或种子，不发布 Worker、管理端或企业端。云和连线是互联示意，不代表真实网络连通性或设备在线证据。未来需要真实网络监测时另立数据来源与状态合同；当前没有新增待处理的 TypeScript 诊断。
