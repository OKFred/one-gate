# 数据库迁移脚本清理计划变更

## 文件与预期行为

| 文件                                                  | 计划变更                                                                             |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `server/scripts/generate-ddl.ts`                      | 移除清空历史迁移目录与旧无账本增量生成，隔离临时目录，传播失败，先生成后写入         |
| `server/packages/core/src/db/initTable.ts` 及参数模块 | 初始化与迁移职责分开，拒绝旧 Node 重放，删除不可达 Worker 增量分支，结构失败停止种子 |
| `server/packages/core/src/db/utils/schema.ts`         | 增加显式严格错误选项供新库初始化使用，保留既有调用的默认行为                         |
| `server/packages/core/src/db/migrations/README.md`    | 标记历史 SQL 用途及旧版本升级限制                                                    |
| `server/apps/server/src/*tool*.node.spec.ts`          | 生成器文件安全、失败与参数边界回归                                                   |
| `docs/database-migrations.md`                         | 当前 SQLite、D1、PostgreSQL 命令及历史文件说明                                       |
| `README.md`、`README_zh_CN.md`                        | 链接统一迁移说明，纠正旧生成器描述                                                   |
| `docs/1022-数据库迁移脚本清理(优化)实际落地.md`       | 完成后记录差异、验证与复盘次数                                                       |

## 交付约束

- 不删除或改写任何已发布迁移 SQL，不重命名 D1 账本文件，不自动重建数据库。
- 当前部门、角色、资产 Node 命令与 PostgreSQL 入口继续可用；本轮不引入新的通用迁移框架。
- 不提交、推送或发布，保留当前分支已有改动。
- 先完成格式与 TypeScript 对比，再进行最多五轮复盘；明确区分工具测试和线上验收，本轮不执行线上写操作。
