# 资产列表视图详细设计

日期：2026-11-08。基线 `bd40d60a`，继续使用 `codex/personal-assets-spaces` 及草稿 PR #19。

资产页默认只展示现有列表，保留搜索、位置/状态筛选、分页、详情及个人位置编辑。顶部沿用仓库已有 MUI exclusive ToggleButtonGroup，提供“列表 / 空间”，重复点击当前选项不清空选择，不持久化偏好，每次进入默认列表。

空间视图单独展示现有 Three.js 场景；列表面板在空间模式隐藏。列表模式不挂载 Canvas，因此不创建 WebGL 或持续帧任务；切回列表时沿用 renderer 的卸载释放流程。列表筛选、分页、所选楼层与详情状态继续由 AssetWorkspace 持有，切换不重置。

“查看本层”先更新场地/楼层筛选并切到列表，DOM 提交后再聚焦、滚动到列表；普通视图切换不抢焦点。详情抽屉在两种视图外共用。无新增 API、权限、数据库、依赖或生产操作；真实状态与演示隔离保持不变。

验证默认列表无 Canvas、视图互斥、切换保留筛选/分页、重复点击、空间查看本层返回及焦点、返回空间重新建立真实 WebGL、动效/拾取回归、移动端键盘与降级。现有空间用例显式进入空间，普通列表用例保持默认。分别保存合成列表与空间截图。
