# 回收站身份隔离详细设计

## 背景与本轮范围

在最新 dev a4f8017e 建立 codex/recycle-bin-auth-isolation，继续完善回收站的边界。多标签共享 localStorage：另一标签换账号后，当前 AuthenticationBoundary 没有订阅跨标签身份变化，旧回收站记录、权限和确认可能继续显示，而请求拦截器每次从 localStorage 读取新凭据。迟到的旧 401 还会中止新账号请求；旧提示关闭回调和 ProtectedRoute 的旧异步 catch 都可能清除新登录。

本轮在公共认证和 HTTP 层隔离身份，回收站作为验收场景。不改变服务端权限、软删除数据结构、30 天期限、资源注册或清理 SQL。另发现的禁用角色权限与资源清理长期 pending 隔离作为独立后续项，不混入本轮。

## 公共会话快照

auth 工具提供可捕获、可同步核对的会话快照，由当前凭据及本页递增代次组成。凭据不写入日志、持久化报告或 DOM。监听同页 AUTH_CHANGED_EVENT 与 localStorage 的 userInfo/clear 事件；支持取消订阅。实际凭据变化、登出再登录和跨标签切换使旧代次失效；同一凭据的姓名／语言更新只同步用户资料，不触发整个业务树重新挂载。

读取时同步核对当前存储，不能只等待 React effect 更新。正常认证写入在凭据变化前轮换独立的 hodor:auth-session 随机标记，同 token 更新不轮换，不改变 userInfo 的字段契约。这样正常 A→B→A 即使事件尚未到达也会使旧会话失效。两项存储写入不是事务，短暂中间状态允许拒绝请求或重新验证，不能把旧业务操作升级到新身份。旧版本或直接改存储的标签没有标记时，消费 StorageEvent.oldValue/newValue 的变化处理 ABA；对事件尚未到达的原始 ABA 不作同步检测承诺。

公共运行状态通过 Symbol.for 在同一浏览器页面的联邦模块副本间共享。区分存储中的当前会话与最近一次页面提交的会话：请求只捕获后者，再同步核对前者，不能因为读取新存储就让仍挂载的旧确认使用新凭据。该机制用于前端状态归属，服务端鉴权仍是授权依据。

## 认证边界与异步操作

AuthenticationBoundary 通过 useSyncExternalStore 订阅公共会话变化，身份不匹配时直接渲染 CHECKING。旧树移除后由 layout effect 提交新页面会话，随后普通 effect 才请求 gate；同 token 的资料变化不触发重建。每次身份变化让受保护业务树及其 PermissionProvider、MenuProvider 重建，清除旧回收站结果、选择与在途响应版本。异步 gate、验证回调和退出结果必须同时属于当前评估和当前会话；卸载或 gate-required 事件也让旧评估失效，避免旧成功响应重新打开业务页面。URL 转移凭据只在边界初始化时接收一次，避免旧 URL 在跨标签退出后复活会话。

ProtectedRoute 的 check/profile 流程捕获同一快照，并在每个异步续体、catch、finally、资料写回和 URL 修改前核对仍处于当前 effect 和当前会话。取消及旧结果不登出、不回写、不显示第二份错误。当前会话验证失败仍保留原有失败处理。

## 请求与提示归属

HTTP 调用捕获发起时会话，实际发送前再次核对，响应成功和失败时也核对。旧会话响应统一作为取消处理，先释放自身队列项，不能触发全局错误提示、TOTP 事件或中止新会话请求。ignoreAbort 仅保留现有取消策略，不能跳过身份隔离。被取消的请求不显示网络错误。

普通 401 的全局提示关闭前再次核对其原始快照；只有当前会话才允许 logout 和跳转，关闭动作本身仍完成。身份切换只丢弃旧请求结果，不自动重放已经发送的写操作，也不声称客户端取消能回滚服务端已执行的变更。

## 验证与发布

先通过隔离双标签场景复现，再补回归：另一标签换账号或登出时旧确认消失；新账号权限和目录重载；旧 200、普通 401、TOTP 401 与旧验证 catch 不影响新会话；旧提示关闭不能清除新登录；同 token 资料变更不重置业务页；A→B→A 不复活旧请求；当前身份真正失效仍按原流程提示。

执行修改前后三端及 E2E TypeScript 比较、变更文件格式检查、认证和回收站完整 E2E、三端构建与 git diff --check。两轮交叉复核后提交 PR，通过 CI 后按既有 dev 自动发布。线上只读检查页面和版本，不切换真实用户身份或构造生产失败，不创建／恢复／清除业务数据。
