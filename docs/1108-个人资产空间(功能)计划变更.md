# 个人资产空间计划变更

日期：2026-11-08。

## 预计文件与职责

| 范围                                         | 预计变更                                                             |
| -------------------------------------------- | -------------------------------------------------------------------- |
| `server/packages/personal/src/asset/`        | model/schema.pg、SQLite/PG repository、service、路由、状态及隔离测试 |
| `server/packages/enterprise/src/`            | 最小脱敏资产公开投影、ServiceRegistry 及组合初始化                   |
| `server/apps/server/src/`                    | 显式 PG 动作白名单、结构契约及迁移测试                               |
| `server/packages/core/src/db/`               | 个人位置表 DDL、菜单、权限、中英文后端错误种子                       |
| `server/apps/server/d1-migrations/`          | 新增编号增量表与种子迁移，保留旧数据                                 |
| `server/apps/server/postgresql-migrations/`  | 新增 PG 增量表及种子；聚合 schema 同步                               |
| `server/scripts/`                            | 定向 DDL、Node 事务迁移复用；不得调用破坏性全量生成                  |
| `server/packages/core/src/types/business.ts` | `personal.asset` 业务键                                              |
| `platform/apps/personal/src/pages/asset/`    | 房屋场景、清单、详情、位置编辑、显式演示数据                         |
| `platform/apps/personal/src/locales/`        | 页面中英文资源                                                       |
| `platform/packages/ui/src/`                  | API 封装、生成的 OpenAPI/权限、菜单名称资源                          |
| `platform/e2e/`                              | 专用真实 personal remote 的脱敏 mock 预览及 UI 验证                  |

## 顺序

1. 基线类型检查及只读结构、presence 合同审计。
2. 输出详细设计与计划（本文）。
3. 并行实现后端私有位置/企业投影与前端房屋视图。
4. 生成定向 DDL、编号迁移、权限与 OpenAPI，加入针对性测试。
5. 运行相关 Node/Worker/PG 与 UI 检查；可用环境不足时逐项明确未执行。
6. 格式和类型对比后按规范最多五轮复盘；输出实际落地记录。
7. 本地可查看预览，小提交推送与 PR；本轮不合并或生产发布。

## 预期影响与不包含

新增当前用户位置数据及只读资产投影，不改资产身份、采集、挂载、告警和回收站。不做采购、财务、任意布局编辑器、新实时服务或新的基础设施授权。生产迁移/种子/数据写入本轮均不执行。

实际在线接通、批准 UUID 映射、真实位置确认是后续独立验收项；模拟预览不能替代。
