# 资产二维拓扑详细设计

日期：2026-11-08。基线 `6b953c24`，继续当前开发分支与草稿 PR #19。

在默认列表和 Three.js 空间之外增加“拓扑”视图。复用 personal 已安装的 ReactFlow 11，使用纯 HTML/SVG 表达场地、楼层、物理资产及待定位关系；不创建 Canvas/WebGL、不新增依赖、后端接口、权限、数据库或生产操作。默认仍为列表，三种视图互斥显示。

首期展示与列表一致的物理资产，每项原 UUID 只出现一次。已知场地/楼层按现有位置字段归组；位置缺失保留在待定位组；已存在且当前可见的 hostAssetId 可显示关联主机边，缺失或不可见的主机不补造节点/边。虚拟资源沿用主机详情入口，不伪造物理位置或额外实体。连线明确标为位置/归属关系示意，不宣称实际 LAN、网络健康或流量。

图布局采用确定性分层排列，不开放连线、节点位置或业务编辑。支持画布平移、滚轮缩放、适配视图和设备点选，原 UUID 打开共享详情；键盘保留原生设备按钮。拖动不能误开详情。状态继续用 effectivePresence、文字和语义色，过期降为未知；明暗主题、窄屏和无 WebGL 环境可用。

拓扑仅在选择时挂载。切回列表/空间后不保留图实例或临时视口，不持久化图状态；现有列表筛选、楼层选择、详情与保存合同保留。图只读取当前已授权快照，无额外请求或隐藏真实身份来源。

验证第三视图切换、无 Canvas/WebGL、真实 pan/zoom、重置、点击/键盘正确 UUID、拖动防误选、完整节点与关系来源、待定位、到期状态、主题/移动、视图释放、默认列表及 Three.js 全回归。使用合成截图，区分本地、当前 CI 与未上线边界。
