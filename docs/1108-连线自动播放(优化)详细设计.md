# 连线自动播放详细设计

用户明确要求取消连线显示及动效的额外开关。3D 空间继续固定显示互联示意线，进入场景后自动播放，不再需要手动确认。

移除 ThreeViewport 的播放状态、按钮与对应中英文词条；删除 renderer 的 setMotion 能力和媒体偏好监听。连线沿用现有距离属性与 30 FPS 动画，不增加依赖或渲染路径。依照本次用户明确要求，减少动态偏好不再暂停该场景连线；不修改浏览器或系统偏好。

保留页面不可见、WebGL 上下文丢失和卸载时的停帧与资源释放；回到可见场景后自动播放。默认列表、2D 拓扑、位置及详情行为保持原有范围，无 API、数据库或后端变更。
