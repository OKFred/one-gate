# 资产楼房透视详细设计

日期：2026-11-08。在 `codex/personal-assets-spaces`、草稿 PR #19 的 Three.js 场景上迭代，基线 `71db752a`。

## 目标与边界

保留 OpenLife 单层住宅和 OpenMind 四层楼的可辨认外墙、屋顶与楼层轮廓，同时能透过建筑外壳看到内部各层设备和状态灯。楼层按钮改为突出当前层，其他层继续可见；不增加视图开关、依赖或空间编辑功能。

本次只修改前端示意、相关测试及文案。资产 UUID、权限、个人布局保存、真实 presence、后端、数据库与生产部署不变。演示仍明确标为合成，真实状态未接通时保持未知。

## 渲染与点选

- 沿用单 Canvas、OrbitControls 和实例化设备。外壳、楼板与屋顶使用低透明度表面和轮廓线，透明面不写入深度；当前层楼板和边框较突出。
- 每层分别排列并绘制属于该层的全部物理设备；状态灯保留原四状态语义，不因未选中楼层伪装为离线或隐藏。
- 建筑外壳不参与设备 Raycaster 阻挡，设备仍按实际可见网格的最近命中解析 UUID。跨层点击沿用已有选择逻辑，同步楼层并打开详情；旋转、缩放、平移及拖动阈值不变。
- 保留无 WebGL 回退、普通清单、当前层键盘设备入口、移动端、主题原地更新、减少动态和资源释放。新增线框几何及材质进入现有 dispose 路径。

## 验证

用户后续明确虚线应动态流动。默认沿用系统减少动态效果偏好；提供单个场景内播放/暂停按钮，用户显式播放可以仅为当前场景开启，显式暂停不随系统媒体偏好切换自动恢复。选择仅保留当前组件生命周期，不写入系统或持久设置。页面隐藏或上下文丢失始终停帧；恢复前台后按当前选择继续。按钮和实际帧流动/静止均需验证。

用明确合成数据验证全层投影与实际跨层射线点选、当前层突出与其他层保留、拖动不误选、移动端键盘、主题和上下文回退。提供新版截图；复用原有数据与权限边界回归。新增或变更源码执行格式、ESLint、前后 TypeScript 比对、相关测试、构建及差异检查，当前提交 CI 成功后更新 PR，保持 Draft，不合并或部署。
