# 平台限额提示计划变更

- 分支：`codex/cloudflare-limit-errors`；基线：main `840f7052`。
- core/errorHandler：新增有界平台限额分类、固定中英文提示、全局处理接入、错误码及 429/503 OpenAPI 响应。
- core/db/translation：登记新增后端错误词条，不执行初始化或线上种子写入。
- 共享 UI 请求层：业务码/边缘页安全识别、中英文文案、保留认证和局部展示机制。
- 测试：Node、Worker 共用后端合同与负例；前端纯逻辑及请求层/登录交互回归。
- 文档：完成后记录实际覆盖、未可读边缘故障的限制、验证结果及复盘次数。
- 本轮不扩大到自动升级套餐、请求重放、数据库迁移、生产重置或与当前问题无关的模块改造。

## 实施期间范围确认

全路由的 429/503 OpenAPI 响应枚举暂不扩展：当前路由封装只挂载部分通用错误状态，补全将引起所有路由及生成类型的大范围变化。此次保留现有通用错误对象结构，运行时新增固定业务码和对应 HTTP 状态；全路由文档枚举单独治理，不留下未接入的 schema 定义。
