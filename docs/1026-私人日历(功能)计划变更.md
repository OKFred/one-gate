# 私人日历计划变更

- 分支 `codex/personal-calendar`，基线 main `aa167bb3`。
- 新增 personal/calendar 模型、双后端仓储、领域服务/挂载和合同测试；追加精确 PG 能力路径。
- 定向生成日历 DDL、D1/PG 编号迁移、Node 事务迁移及结构检查；不修改历史迁移。
- 新增管理端日历页面、站内提醒宿主、共享 API 封装与自动生成 OpenAPI 类型、中英文文案。仅对受保护账号页面增加 `/calendar`，首页只加一个快捷入口。
- 新增隔离日历/提醒 UI 验证，调整既有 fixtures 的空提醒响应以避免重复网络与越权测试误报。
- 用户明确修正为仅站内提醒：不创建此对话自动化或邮件；浏览器关闭时不承诺后台通知。
- 上线后通过本人已登录界面创建一次首条续约日程，核对用户要求的时间及 UTC 转换，保存后再次读取确认，不用迁移种子代替真实创建；具体内容只留在私人日历和仓库外验收材料。
- 完成后补实际落地、模拟/真实验收、发布与数据保留记录，延续现有本地检查和 CI 跳过方式。
