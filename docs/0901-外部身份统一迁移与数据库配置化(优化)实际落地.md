# 外部身份统一迁移与数据库配置化实际落地

## 当前状态

状态：代码迁移、远程 D1 migration、数据库配置、`dev` 合并部署、生产登录验收和旧 Secret
退役均已完成。

Hodor 只保留账号密码与标准 OIDC Identity Center。GitHub、飞书由 one 统一承接，Hodor 不再直接
读取 Provider 配置、交换 Provider Token 或维护新的旧式 OAuth 绑定。历史 OAuth 表与 migration
仍原样保留，未删除或迁移历史数据。

## 实际完成范围

### 数据库独占 SSO 配置

- 无外键单例表 `system_sso_connection` 保存 issuer、Client ID、audience、允许租户、精确 redirect
  URI、`draft | ready | disabled`、乐观版本和最近测试信息。
- D1 migration `0010_sso_connection_configuration.sql`、Node migration、Drizzle model、初始化 SQL 和
  Schema Contract 已落地；既有 migration 未改写或重排。
- 管理接口 `get/save/test/disable` 继续要求 Hodor 管理员、有效 Token 和 TOTP：
  - `save` 使用 `expectedVersion` 并回到 `draft`。
  - `test` 校验 HTTPS、OIDC discovery、issuer、JWKS 和 redirect URI 后原子切换为 `ready`。
  - `disable` 使用条件更新，版本冲突返回 409。
- SSO 登录、绑定和回调现在每次只读取权威数据库；没有配置、`draft` 或 `disabled` 都返回现有
  `SSO_CONFIGURATION_ERROR` 503，不再回退环境变量。
- PKCE transaction 只使用 `HODOR_AUTH_MASTER_KEY` 加解密；旧
  `OAUTH_SENSITIVE_DATA_KEY` 名称不再参与运行时解析。

### 外部 Provider 所有权迁移

- Hodor auth service 不再导出 GitHub、飞书和微信 WIP API；旧 `/oauth/*` 与 `/wechat` 不在 Hono
  路由树或匿名鉴权白名单中，统一抵达 JSON 404。
- retired-route 分类只允许旧路径越过 TOTP 预检抵达统一 404，不会绕过 Hodor Token 鉴权或恢复
  Provider handler。
- 删除 Hodor 活动 OAuth application、Provider adapter、state、cipher、repository、HTTP 实现和
  旧 callback 页面。
- 用户资料响应删除 `githubUsername`、`oauthBindings`；OpenAPI 导出和前端生成类型同步更新。
- 登录页的有效认证方式仅为密码与 Identity Center；账号页只保留密码与 SSO 绑定/解绑。
- one production 的 GitHub、飞书 Provider Connection 与租户认证策略已配置；未绑定外部身份不会
  自动注册 Hodor 用户。

### 部署配置退役

- PR #101 将 SSO 解析改为数据库独占，并从 CI、Wrangler、生成 Worker 类型和 `.env.example`
  删除五个 `SSO_*` 与 `OAUTH_SENSITIVE_DATA_KEY`。
- 部署契约以负向列表阻止 GitHub、飞书、旧 OAuth、旧 SSO bridge 变量重新进入 Workflow、Wrangler
  或示例配置。
- 生产验收成功后，已从 Hodor Worker 删除 GitHub/飞书直连 6 项、旧 OAuth 2 项和 `SSO_*` 5 项；
  已从 GitHub Repository Secrets 删除上述项目及已退役的两个 Hodor Cloudflare Access 变量。
- 保留 `HODOR_AUTH_MASTER_KEY`、`HODOR_TOTP_GATE_SECRET`、JWT、移动端密钥、跨域白名单和前端部署
  URL；Secret 列表复核只返回名称，没有读取或输出值。

## 与计划的差异

- 历史 Hodor OAuth 表按计划保留，但不再有活动代码读写；物理清理仍需独立 migration 和观察期。
- 旧 Provider 应用本身及历史授权未在本迭代删除；本轮只完成 Hodor 代码、配置与 Secret 所有权
  退役，避免把不可逆第三方清理混入登录切换。
- Hodor 旧 confidential OIDC Client 已停用，新 public S256 PKCE Client 保持启用；one-authz 的
  confidential 服务 Client 独立保留。
