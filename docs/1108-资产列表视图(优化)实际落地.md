# 资产列表视图实际落地

日期：2026-11-08。基线 `bd40d60a`，继续更新现有草稿 PR #19。

## 实际结果与计划差异

默认只显示现有资产列表，顶部提供与仓库其他页面一致的 MUI“列表 / 空间”互斥切换。列表保留搜索、位置/状态筛选、分页、详情及个人位置编辑；选择不持久化，每次进入默认列表。

空间按需挂载，切回列表卸载 Three.js 并释放 WebGL/帧任务。再次进入创建新场景，楼层选择和列表状态保留，视角与临时动效选择按新场景初始化。列表面板在空间模式仅隐藏，不复制或改写原列表 DOM；避免无关的整块 JSX 重排。共用详情抽屉保留。

“查看本层”设置过滤条件并切回列表，在提交渲染后的 effect 中聚焦、滚动；普通切换不抢焦点。重复点击当前选项不会清空视图。

实现与计划一致。未加入持久偏好或额外 Three 模块拆分，未改 API、权限、数据库、真实 presence 或生产配置。
