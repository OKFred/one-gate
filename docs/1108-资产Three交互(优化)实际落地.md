# 资产 Three.js 交互实际落地

日期：2026-11-08。基线 `ecd7c085`，继续更新 `codex/personal-assets-spaces` 与草稿 PR #19。

## 实际结果

旧 SVG 房屋与平面互联条已替换成单个 Three.js WebGL2 场景，包含 OpenLife 单层住宅、OpenMind 四层楼、实例化设备与中性动态虚线。左拖旋转、滚轮缩放、右拖平移；短点击经 Raycaster 命中原资产 UUID，接回已有详情。拖动、多指、取消和失去上下文后不触发旧设备选择。

楼层、当前层设备按钮、完整清单和键盘入口继续可用。1000 项上限内的当前层设备全部实例化，并按示意网格缩放，不再只画前五台。未知位置不放进房屋，虚拟子资源不增加伪物理实体。源身份、位置存储、权限、接口、数据库、采集及真实 presence 合同均未变。

仅增加 personal 的 `three@0.187.0` 和开发类型 `@types/three@0.187.0`，未引入 React Three Fiber、Drei、外部模型或物理模拟。开发类型存在传递依赖，场景运行时不使用它们的物理/统计功能。

## 计划差异与复核

实施与计划一致。额外补了本地预览的深浅主题开关，以及仅 CI 浏览器使用的 SwANGLE 软件图形驱动，使无 GPU 的测试 runner 仍走真实 WebGL2 路径；没有修改生产浏览器设置。顺带校正合成 fixture 的业务码层级，不改实际后端合同。

共两次集成复核，分两批修正：

1. 修正主题更新会销毁上下文和重置视角：改为原地更新颜色，灯光保持中性白；相机及原 GL 上下文保留。
2. 取景从经验距离改为真实包围球、横纵 FOV 和余量；尺寸变化保持用户方向和相对缩放。独立数值复核确认多个窄屏比例的楼板均处于视锥内。
3. ready 只由实际成功渲染发出；隐藏初载不假报就绪。动画早停同步暂停状态，失效输入清理，资源释放幂等。
4. 修正测试在 Drawer 打开时查询被隐藏背景的错误，保留媒体偏好、实际相机与动画状态的严格断言。
5. 最终风格检查要求预览入口只负责挂载，将主题组件拆到独立文件；随后重新执行主题交互、预览类型和完整变更文件 ESLint 检查。

## 生命周期与交付边界

场景颜色/业务数据变化保留相机。动态连线限帧，隐藏、减少动态、丢失上下文时停止；卸载释放资源、监听器、observer、controls 和帧任务。无 WebGL2 时给出提示，普通设备入口保留，不无限重建。

本地合成预览沿用 `http://127.0.0.1:4185/#/personal/asset`，右上显式切换演示。开发预览服务仅绑定 localhost；没有真实登录凭据、生产数据或源身份。后端及数据库未变，本轮不重复执行生产或迁移操作。

新版验证属于本次 Three.js 实现，不能引用上一 SVG 版本的截图或旧 CI 结论代替。真实 presence、实机触屏、不同实体 GPU 的性能及长时间占用尚未验收；未合并 main、未部署生产。

没有新增未解决的 TypeScript 诊断。后续若扩展真实户型、空间编辑或新的设备身份，需独立设计；本轮不预先增加这些功能。
