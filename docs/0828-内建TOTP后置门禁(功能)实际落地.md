# 内建 TOTP 后置门禁实际落地

## 1. 落地范围

本轮在 `node_server` 的 `codex/sso-gateway-integration` 分支实现“主认证 → TOTP → 系统”。
未修改 one-sso、D1 表、用户数据、OAuth 协议、设备回调协议或 WebSocket 协议。

## 2. 后端实现

- 新增 `admin/system/auth/totp-gate` 垂直切片：
  - Domain 固定 RFC 6238 参数、门禁声明、错误码和常量时间比较。
  - Application 提供状态查询、验证码验证、Token 绑定会话和端口。
  - Infrastructure 提供 Web Crypto、环境 Secret、Node 内存协调器和结构化审计日志。
  - HTTP 接口提供 `gate/status`、`gate/verify`、`gate/logout` 并注册 OpenAPI。
- 新增生产 Cookie `__Host-hodor-totp-gate`，签名载荷只包含用户 ID、Token HMAC 摘要、密钥指纹和时间。
- 新增 SQLite-backed `TotpGateCoordinator` Durable Object，通过 RPC 串行处理失败限流和时间步消费。
- 新增运行时无关的认证路由策略；主认证、门禁控制、机器凭证和 WebSocket 白名单显式分类。
- 删除 Cloudflare Access Origin JWT 中间件及其两个配置项；Worker/CI 改用 `HODOR_TOTP_GATE_SECRET`。
- 全局错误响应新增稳定 `data.code`，失败日志沿用 `requestId` 并记录业务错误码。

## 3. 前端实现

- 新增共享 `AuthenticationBoundary`，状态为：
  - `PRIMARY_AUTH_REQUIRED`
  - `PRIMARY_AUTH_CALLBACK`
  - `TOTP_REQUIRED`
  - `READY`
- admin、enterprise、personal 的菜单和权限 Provider 只在 `READY` 内挂载。
- 密码、OAuth 和 one-sso 登录成功后只保存 Hodor Token；回调不再加载菜单或权限。
- OAuth/SSO 账号绑定回调需要已有 Token 和门禁 Cookie；门禁过期时保留当前回调 URL，验证后继续。
- 返回 enterprise/personal 的 URL 仅接受配置内 Origin，并在 TOTP 成功后才附带现有跨应用 Token。
- Axios 将 `TOTP_GATE_REQUIRED` 与会话过期分离；动态码错误不会清除 Hodor 登录态。
- 显式退出先调用 `gate/logout` 清 Cookie，再清本地 Hodor 登录态。

## 4. Secret 与登记文件

- 新增 `totp:enroll` 脚本，生成 20 字节 Base32 密钥、离线 QR/动态码页和可选本地 `.dev.vars` 同步。
- 真实文件保存在仓库忽略的 `.secrets/`，终端只输出文件路径和短指纹。
- 已生成独立 production 登记文件并同步到本地 `.dev.vars`；密钥和动态码未写入 Git、测试输出或本文档。

## 5. 已验证结果

- 服务端 TypeScript 构建通过。
- Node 定向测试 7 个文件、26 个用例通过，覆盖 RFC 向量、输入规范化、用户/Token 绑定、过期、重放、限流、配置缺失、日志脱敏、路由策略、OpenAPI 和部署契约。
- Workers 定向测试 1 个文件、2 个用例通过，覆盖 Durable Object 并发消费和客户端失败限流。
- admin、enterprise、personal 生产构建通过。
- Playwright Mock 6 个用例通过：密码、OAuth、one-sso 主认证后停在 TOTP，且 TOTP 前菜单/权限请求数为零；验证后 Provider 只初始化一次，刷新复用门禁状态。
- Worker `wrangler deploy --dry-run` 通过，确认 `TotpGateCoordinator` 绑定和 SQLite Durable Object migration 可打包。
- 变更文件 ESLint 无错误；保留两个旧中间件既有的 6 个 warning。`git diff --check`、UTF-8 无 BOM、LF 和新增 `any/as any` 检查通过。
