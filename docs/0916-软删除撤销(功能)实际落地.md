# 15 秒撤销删除实际落地

## 交付结果

已在 `codex/soft-delete-undo` 完成公共撤销能力及部门接入，基于 `origin/dev` 的 `2ed0ba6a`。本轮交付为分支代码与本地验证，未合并到 dev、未部署或操作生产数据。

- 部门删除成功浮窗包含名称、剩余秒数和撤销按钮；每次删除独立处理。
- 服务端同时要求本次删除人和当前部门删除权限，不要求回收站恢复权限。其他超级管理员也不能快速撤销他人的删除。
- 新删除接口以页面看到的更新版本做条件更新，直接返回精确删除版本；撤销以执行时 SQL 时钟严格限制未满 15 秒，保留原 ID 和启用状态。
- 重名、父部门失效、权限撤回、过期和版本冲突分别处理。超时/断网/5xx 保持结果未知，重试只携带原删除版本；不会重发删除。
- 明确恢复成功和列表刷新失败分别展示。失败浮窗可手动关闭，关闭后页面仍保留重新加载入口。
- 同账号站内切页保留入口，换账号、退出及二次验证锁屏清除旧入口；旧响应不能覆盖新身份或新查询结果。
- 原删除数值响应、30 天回收站恢复、定时清理及数据库结构保持兼容。

## 公共合同与业务边界

| 入口                                                  | 实际行为                                                                              |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `POST /api/v1/admin/system/department/deleteWithUndo` | 输入 `id/expectedUpdateTimeUtc`，返回资源类型、ID、删除版本、撤销截止时间、服务端时间 |
| `POST /api/v1/admin/maintenance/recycle-bin/undo`     | 已认证的通用入口，经显式注册的可选 undo 适配器执行本人权限与业务约束                  |
| 部门 `listAll`                                        | 额外返回必填且可空的 `updateTimeUtc`，供新删除请求提交页面所见版本                    |

core 仅增加窗口常量、收据及适配器合同，没有反向依赖部门。公共 UI 协调器通过业务传入的可重试/状态变化错误码处理其他资源，不硬编码部门错误码。新 API 已从本地应用导出 OpenAPI 并生成前端类型。

## 与计划的差异

| 项目               | 实际调整与理由                                                                                                        |
| ------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 列表版本字段       | 补齐 listAll 的 schema 与实际 SELECT；原列表没有更新时间，不能在删除前临时读取新版本代替页面版本                      |
| 删除响应损坏或丢失 | 一并防御：没有可信收据时保持结果未知，不生成撤销入口，不自动重试删除                                                  |
| 错误分类           | 抽为可独立测试的纯函数；HTTP 200 业务拒绝和 AxiosError 统一识别，TOTP 503/429 不误当会话切换静默丢弃                  |
| 关闭浮窗后刷新失败 | quiet 模式保留非 Alert 的重新加载按钮，避免重复错误提示和页面空白无入口                                               |
| 查询版本保护       | 部门树只接纳最新请求结果；失效查询和卸载不回写 loading 或列表                                                         |
| 时间展示           | 保守扣除整个请求耗时，并结合单调时钟与墙钟累计；系统时间前跳可能提前关闭入口，后跳/睡眠不能延长期限，最终由数据库判定 |

没有新增数据库字段、默认值、DDL、迁移、操作结果表、状态查询接口、菜单或可分配权限。其他业务尚未接入撤销。
