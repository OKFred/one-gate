# 数据库初始化说明

## 超级管理员初始化

系统启动时会自动检查并初始化超级管理员角色和账号。

### 默认配置

- **用户名**: `superadmin`
- **密码**: `Admin@123456`
- **角色**: 超级管理员（ID: 1）
- **权限**: 拥有所有系统权限

### 自定义配置

可以通过环境变量自定义超级管理员的用户名和密码：

```bash
# 自定义超级管理员用户名
SUPER_ADMIN_USERNAME=admin

# 自定义超级管理员密码
SUPER_ADMIN_PASSWORD=MySecurePassword123!
```

### 安全建议

⚠️ **重要提示**：
1. 首次登录后，请立即修改超级管理员密码
2. 生产环境中务必通过环境变量设置强密码
3. 不要在代码中硬编码生产环境的密码

### 初始化流程

1. 检查超级管理员角色是否存在
   - 如果存在，跳过角色初始化
   - 如果不存在，创建超级管理员角色（ID: 1）

2. 检查超级管理员账号是否存在
   - 如果存在，跳过账号初始化
   - 如果不存在，创建超级管理员账号

3. 密码使用 bcrypt 加密存储（盐轮数：12）

### 超级管理员权限

超级管理员拥有以下权限：
- `system:*` - 所有系统管理权限
- `user:*` - 所有用户管理权限
- `role:*` - 所有角色管理权限
- `department:*` - 所有部门管理权限
- `mail:*` - 所有邮件管理权限

### 日志输出

初始化成功时会在控制台输出：
```
开始初始化数据库...
✓ 超级管理员角色初始化成功 (ID: 1)
✓ 超级管理员账号初始化成功 (用户名: superadmin)
  默认密码: Admin@123456
  ⚠️  请在首次登录后立即修改密码！
✓ 数据库初始化完成
```

如果角色或账号已存在：
```
开始初始化数据库...
超级管理员角色已存在，跳过初始化
超级管理员账号已存在，跳过初始化
✓ 数据库初始化完成
```
