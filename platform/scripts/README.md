# 多语言扫描脚本说明

## 概述

这个脚本用于扫描前端代码中的多语言调用，并与 initTranslation.ts 中的定义进行比对，生成缺失和未使用的多语言键报告。

## 正则表达式改进

### 原始正则：`t\('(.*)'\)`

**问题**：

- 贪心匹配，单行多个翻译会被合并成一个
- 只支持单引号
- 不处理空格

### 改进版本：`t\(\s*['"\`]([^'"\`]+)['"\`]\s\*\)`

**优点**：

1. `\s*` - 允许括号和引号之间有空格
2. `['"\`]` - 支持单引号、双引号、反引号三种引号类型
3. `[^'"\`]+`- 使用字符类而不是贪心匹配`.\*`，避免单行多个翻译被合并
4. 全局标志 `g` 确保捕获所有匹配项

## 脚本使用

### 运行脚本

```bash
node scripts/scan-i18n.js
```

### 输出文件

生成的报告保存到项目根目录的 `i18n-scan-report.md`

### 报告内容

1. **统计摘要** - 文件数、键数统计
2. **缺失的多语言键** - 前端使用但未在 initTranslation.ts 中定义的键及其使用位置
3. **未使用的多语言键** - 在 initTranslation.ts 中定义但前端未使用的键

### 对于未使用的多语言键

可以考虑从 initTranslation.ts 中删除，或标记为过期/保留。

## 注意事项

1. 脚本只能检测形如 `t('key')` 的调用，不支持动态键名（如 `t(variable)`）
2. 排除了模板字符串中的变量（包含 `${`）
3. 支持多种文件类型：`.ts` 和 `.tsx`
4. 自动跳过 `node_modules` 和隐藏目录

## 扩展功能建议

1. 可以添加检测 i18n 初始化后是否真正生效
2. 可以导出为 JSON 格式方便其他工具处理
3. 可以添加国际化完整性检查（是否所有键都有所有语言的翻译）
4. 可以生成缺失翻译的模板 JSON
